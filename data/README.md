# Data

Helix uses two deliberately separated data sources.

## BANKING77

BANKING77 is an external English intent-classification benchmark. Helix does not commit the upstream CSV files. The repository pins the upstream Git revision and file checksums in `configs/data/banking77.json`, then materializes derived train, validation, and untouched test JSONL files locally with:

```bash
uv run python scripts/prepare_banking77.py
```

The generated files live under `data/generated/` and are excluded from Git. BANKING77 remains subject to its original CC BY 4.0 licence and attribution requirements; it is not relicensed under Helix's Apache-2.0 licence.

The official test split is never used to fit parameters, choose models, tune thresholds, or select prompts. A frozen set of source-training rows is quarantined before validation construction because the Phase 1 audit found exact or very-high-similarity counterparts in the official test split.

## HelixBank Policy Corpus v1

`HelixBank Policy Corpus v1` is an original fictional benchmark corpus owned by this repository. It contains:

- 154 policy and FAQ documents;
- 308 golden support queries;
- 616 graded query-document relevance judgments;
- current and archived evidence;
- ambiguous, missing-evidence, conflicting-evidence, and safe untrusted-content fixtures.

The corpus is generated by `src/helix_support_intelligence/data/helixbank.py`. The frozen manifest is committed under `data/synthetic/helixbank-policy-v1/`; the JSONL corpus is reproducible byte-for-byte using:

```bash
uv run python scripts/materialize_helixbank.py
```

Do not replace fictional material with real customer data or proprietary bank policies.

## Contracts

Machine-readable schemas under `data/contracts/` define the Phase 1 boundaries for ticket events, routing, retrieval, generation, safety cases, policy documents, golden queries, and relevance judgments. Later phases may extend contracts only through an explicit compatible revision or ADR.

## Validation

Run the offline Phase 1 invariants with:

```bash
uv run python scripts/validate_phase1_data.py
```

Network access is not required for this validation. Downloading BANKING77 is a separate, explicit operation.
