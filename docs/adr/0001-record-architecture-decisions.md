# ADR 0001: Record Architecture Decisions

- Status: Accepted
- Date: 2026-08-18

## Context

Helix has a finite multi-phase scope. Architectural changes must remain reviewable and must not quietly expand v1.

## Decision

Material architectural decisions are recorded as numbered Markdown ADRs under `docs/adr/`. Each record states its context, decision, consequences, and status. Accepted ADRs are immutable; a later ADR supersedes them when necessary.

## Consequences

Architectural reasoning remains visible, scope changes become explicit, and future simplification or replacement has a traceable basis.
