# Security Policy

## Supported versions

Helix is pre-1.0 research software. Security fixes are applied to the latest commit on `main`; no older version is currently supported.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, pull request, or demonstration.

Use GitHub's private vulnerability reporting for this repository. Include:

- the affected revision;
- a concise description and impact assessment;
- safe reproduction steps using fictional data;
- any suggested mitigation.

Do not include real customer data, credentials, active secrets, destructive payloads, or attempts against systems you do not own.

Receipt will be acknowledged when practical. Validation, remediation, and coordinated disclosure timing depend on severity and reproducibility. This project makes no commercial response-time commitment.

## Scope

The repository is a read-only research and portfolio system. Account access, financial transactions, real customer data, production credentials, and unrestricted tool execution are outside its authorized scope.
